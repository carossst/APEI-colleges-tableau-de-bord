# Val d’Oise — Matrice globale (2021/2023/2024)

Static page ready for GitHub Pages.

## Structure
- index.html
- style.css
- app.js
- data/matrice-globale.json

## Deploy on GitHub Pages
1) Put these files at the root of your repo (or in /docs).
2) GitHub: Settings → Pages → Build and deployment
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /(root) or /docs (depending on where you put the files)
3) Open the GitHub Pages URL.

## Update data
Edit `data/matrice-globale.json` and commit.
