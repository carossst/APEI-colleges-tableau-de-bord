# Analyse d'impact qualitative APEI - Val d'Oise

Cette page propose une lecture transversale des projets APEI par année de jury.

Le périmètre actuellement affiché couvre 12 collèges documentés pour 13 projets, sur les jurys 2017, 2018 et 2021.

La page ne constitue pas un classement. Elle présente des repères qualitatifs sur 5 axes communs : espaces, enseignements, outils numériques, relation aux élèves, relation aux parties prenantes.

Les jurys 2017, 2018 et 2021 correspondent aux cohortes comparées. Les analyses 2023 et 2024 correspondent aux documents sources mobilisés pour documenter ces jurys.

Le jury 2017 est documenté par l'analyse 2023. Le jury 2018 est documenté par l'analyse 2024 en mesure de clôture. Le jury 2021 est documenté par l'analyse 2024 en mesure de mi-parcours.

Seuls les collèges disposant d'une base qualitative exploitable sur les 5 axes sont affichés.
